# 散布計画 計算 (spray_calc)

やまびこ(共立)散布機（ブームスプレーヤ／スピードスプレーヤ／動噴 等）向けの
散布量シミュレータ。スマホ対応の静的 Web アプリ（Vite + React + TypeScript）です。

## 機能

1. **バランス計算** — 反当散布量 R・散布幅 W・走行速度 V・ノズル総吐出量 Q・
   圃場係数 F のうち 1 項目を空欄にすると、残り 4 項目から自動で逆算します。
   基本式は `Q = R × W × V × F ÷ 60`。
   入力検証・計算式表示・結果コピー・URL 共有・入力値保存（W/V/F）に対応。
2. **ノズル設定から計算** — ノズル（モデル or 手入力）と運転圧力・本数から
   ノズル総吐出量 Q を算出（流量は圧力の平方根に比例: `q ∝ √P`）。結果は
   バランス計算へ反映できます。
3. **機器・ノズル提案** — **作物 → 生育ステージ → 散布方法** の順に散布する場面を
   決め、その場面の散布量・散布幅・走行速度を既定値として入れたうえで、必要総吐出量と
   やまびこ(共立)の適合機種・ノズル設定を提案します。動噴・SSV は
   **吸水量 × 0.8** を実用吐出量として判定します。

   - **散布量は場面ごとのレンジ** — 反当散布量は作物ごとの1値ではなく、
     生育ステージ×散布方法ごとに「下限〜標準〜上限」を持ちます（水稲の穂ばらみ期でも
     ホース散布 80〜150 L/10a に対し少量散布は 20〜30 L/10a、りんごの休眠期散布は
     生育期より多量、など）。レンジを外れた入力には警告を出します。
   - **散布幅の意味を方法ごとに明示** — ブームは機械の全幅、送風散布(SS)は
     **樹列間隔**、ホース散布は噴口の有効幅。既定値も作物（樹列間隔）や
     機種（ブーム全幅）から入ります。
   - **作物に使えない機種は出さない** — 機種は適用作物カテゴリ×散布方法で絞り込み、
     ノズルも散布方法に応じた種別・圧力帯（ブーム＝平板扇形 0.2〜0.5MPa、
     SS＝円錐 1.0〜3.0MPa）で提案します。
   - **薬液・薬剤・タンク回数** — 面積・散布回数・希釈倍数から総薬液量と薬剤量、
     機種ごとのタンク1杯あたり散布面積と必要杯数を表示します。

   対象品目は水稲／畑作（麦・大豆・ばれいしょ・てんさい）／露地野菜（キャベツ・
   はくさい・ねぎ・たまねぎ 他）／施設野菜（トマト・きゅうり・なす・いちご）／
   果樹（りんご・なし・ぶどう・もも・かんきつ・かき）／茶。

## データスキーマと出典

データは `src/data/` にあり、各レコードは `source`（`provenance` / `verified` /
`sourceUrl` / `updatedAt`）を持ちます。機種は `machines.ts`、ノズルは `nozzles.ts`、
作物（品目×生育ステージ×散布方法の散布量レンジ）は `crops.ts`、散布方法は
`sprayMethods.ts`、機種×作物×ノズルの個別推奨は `compatibility.ts`。
散布の前提条件の解決・入力の妥当性判定・機種の絞り込みは `lib/cropPlan.ts`、
実用吐出量（吸水量×0.8 等）は `lib/selection.ts`。

機種の適用範囲は品目単位ではなく**作物カテゴリ**（水稲／畑作／露地野菜／施設野菜／
果樹／茶）で持つため、品目を追加しても機種側の修正は不要です。`compatibility.ts` は
そこから導けない個別の推奨ノズル・圧力だけを上書きする層です。

- `iso-standard` … ISO 10625 規格に基づく値（平板扇形ノズルの色分け・流量）
- `maker-catalog` … やまびこ(共立)公式の製品情報。公式詳細ページで確認できた機種
  （BSM511R/512R/513B/E、SSV6150F、WGR617V-10、VRC4570F2-8 等）を `verified:true`、
  相互確認のみのものは `verified:false`（要確認）で収録
- `estimated` … 未確認の推定値（作物×生育ステージ×散布方法の散布量レンジ、
  作物×ノズルの慣行マッピング等）。散布量レンジは農薬ラベルに記載される希釈水量の
  一般的な範囲を目安にしたもので、**入力値が現場感覚から外れていないかの確認用**です

> やまびこ製品に限定。ノズルは純正＋ISO標準を主体とし、他社（ヤマホ）は技術参考
> リンクのみ残しています。乗用管理機など諸元未確認の機種は順次拡充します。

まず公開情報で初期化し、後からメーカ公式の実データに差し替えれば、UI のバッジ
（確認済／要確認）と提案精度がそのまま向上します。`verified` を `true` にする際は
一次情報での確認を前提とします。

> 提案結果・散布量の目安は参考値です。実際の散布は機器の取扱説明書・農薬ラベル・
> 地域の防除基準に従ってください。
